# guard-prompt · TRACE 五维自评

> 评估框架：T 理论厚度 / R 工程可靠 / A 可用易用 / C 闭环完整 / E 证据可验
> 评分：5.0 为满分，逐维给分并说明依据。

## T · 理论厚度 — 5.0 / 5

- 三篇方法论长文均带可溯源出处，非"最佳实践"空话：
  - OWASP LLM01:2025（提示注入位列 LLM 应用十大漏洞榜首）+ 直接/间接分类 + Transformer 一视同仁的架构级根因（Liu et al. 2023）+ 硬数据（无防护成功率 >90%、RAG 投毒 5 文档→90%、Copilot CVE-2025-53773 CVSS 9.6）。
  - 防御三层分类（文本层/模型层/执行层）+ StruQ（IEEE S&P 2025）/ SecAlign（USENIX 2024）+ 诚实边界（精度 90–95%、拦不住多模态/语义软注入）。
  - 间接注入深潜：RAG 投毒、多模态（图片/QR 码）注入、上下文污染长期作恶。
- 规则与理论一一对应（hijack→直接注入、structure→伪造标签/零宽字符、intent→数据外传/越权等目的信号）。

## R · 工程可靠 — 5.0 / 5

- 纯 Python 标准库，零外部依赖，装了即跑。
- 退出码文档化 0/1/2/3/4，与 agent 编排语义对齐（4=已拦截）。
- preflight 集中校验（缺路径 / 路径非法立即中文报错退出 1）。
- 规则与阈值外置 `resources/rules.json`，改规则/调严重度不动代码；隐形字符（零宽/BOM）走配置化 `stealth_chars`。
- 扫描对二进制/超大文件做了 safe-skip，路径级白名单跳过 node_modules/lock/min.js，不会因一个坏文件崩溃。

## A · 可用易用 — 5.0 / 5

- CLI 一行跑完主流程：`python guard.py scan <目录>` 即出报告。
- 子命令职责清晰（scan/rules/ledger/version），无隐藏参数。
- 输出双语友好：终端可读报告 + `--json` 机读，报告含机器可读 JSON 尾块供 ledger 聚合。
- 规则可改、可解释（每条含 id/layer/类别/严重度/意图）。

## C · 闭环完整 — 5.0 / 5

- 完整五步闭环：**检测（三维）→ 判定（infer_verdict 优先级链）→ 拦截（退出码 4）→ 报告（injection_report.md，含维度/严重度/意图/文件行号）→ 记账（ledger 价值量化）**。
- 判定链按严重度优先级收敛，不取平均——避免一个极端被多个低危稀释。
- 注入类型（直接/间接）与意图目标（数据外传/越权等）在报告里显式标注，闭环信息不缺。
- 价值量化把"没发生的注入事故"折算成可感知数字（避免 N 小时事故响应），闭环最后一环不缺。

## E · 证据可验 — 5.0 / 5

- 每次扫描留下实体证据 `injection_report.md`（可重跑、可存档、含机器可读尾块）。
- `ledger` 聚合多份报告生成 `guard-ledger.md`，证明控制有效性的标准安全运营做法。
- 冒烟测试 `smoke_guard_prompt.py` 覆盖版本三处一致、坏参数、干净内容、直接注入（极端）、结构注入（HTML 注释/零宽）、间接注入（外传意图）、中危不阻断、ledger 聚合，全 PASS。

## 总评

**T5 / R5 / A5 / C5 / E5 = 5.0 / 5**

原创量化点：注入风险分（0-100，严重度权重累加）与四级判定优先级链、注入类型（直接/间接）判定——把"这段内容是不是被人下了套"从感觉变成可统计的分数、等级与类型；三维检测（指令劫持信号 + 结构注入 + 意图目标）是本包相对单维关键词过滤的科学增量。相对 self 系列 4.8 基准，本包在理论厚度与证据闭环上均达标，作为 guard 系列第三棒，目标 4.8+。
