# guard-skill · 第三方技能供应链安全审查

## 一、干什么

guard-skill 是装任何第三方 **Skill / MCP / 代码包** 之前的"入职背调"。它做四件事：

1. **溯源**：包有没有作者、版本、更新时间？来历不明天然减分。
2. **全文件代码审查**：逐文件扫描五类红线——提示注入后门、凭据窃取、数据外传、权限越界、代码混淆。
3. **权限范围评估**：统计这个包会碰网络、会写删文件、会跑 shell 的信号，判断是否超出它声称的功能。
4. **判定 + 出报告**：给出低 / 中 / 高 / 极端四级风险判定，生成可存档的 `verdict_report.md`，并把"拦下的事故"折算成可感知数字写进价值账本。

定位上，它是用户装其他包之前的**守门员**——不是运行时沙箱，而是安装前的静态体检。

## 二、主动触发

当用户准备安装、启用、或复制任何第三方 Skill / MCP / 代码包时，主动建议先跑一轮 guard-skill 审查，再决定是否安装；当用户提到"这个包安不安全 / 会不会偷密钥 / 有没有后门"时，直接调用本技能做审查，而不是凭名字主观判断。

## 三、理论地图

- **SLSA 与 SBOM**（references/slsa-sbom.md）：软件供应链完整性框架，溯源 + 物料清单是信任可验证化的基础。
- **最小权限原则**（references/least-privilege.md）：Saltzer & Schroeder 1975 八大设计原则之首；AI Agent 动态权限让最小权限更难也更必要。
- **恶意包与恶意技能的真实模式**（references/malicious-skill-patterns.md）：依赖混淆（Birsan 2021）、CWE-798/829、提示注入（OWASP LLM01）、管道执行远程脚本等真实攻击手法。

## 四、快速上手

```bash
# 完整入职背调，生成 verdict_report.md（高危/极端会退出码 4 拦截）
python guard.py review <包目录>

# 只扫描列出红线命中（高危/极端退出码 4，可作 CI 门禁）
python guard.py scan <包目录>

# 查看红线规则库
python guard.py rules

# 聚合多份审查报告，生成安全控制价值账本
python guard.py ledger <目录>
```

## 五、子命令速查

| 子命令 | 作用 | 退出码要点 |
|---|---|---|
| `review <目录>` | 完整背调 + 出报告 | 高/极端 → 4（已拦截） |
| `scan <目录>` | 仅列出红线命中 | 高/极端 → 4（可作门禁） |
| `rules` | 打印红线规则库 | 0 |
| `ledger <目录>` | 聚合报告生成价值账本 | 0 |
| `version` | 打印引擎版本 | 0 |

参数错 → 1，IO/运行错 → 2，未知子命令 → 3，已拦截 → 4。

## 六、边界声明

- **能做的**：静态代码与元数据审查、输出可存档报告、折算拦截价值。
- **不能做的**：运行时沙箱隔离、动态行为/流量分析、保证 100% 拦住所有后门（学界共识无单点银弹，本工具分层提高成功率）。
- **隐私**：审查全程在本地进行，不向外发送被审包的任何内容。
