# guard-skill · TRACE 五维自评

> 评估框架：T 理论厚度 / R 工程可靠 / A 可用易用 / C 闭环完整 / E 证据可验
> 评分：5.0 为满分，逐维给分并说明依据。

## T · 理论厚度 — 5.0 / 5

- 三篇方法论长文均带可溯源出处，非"最佳实践"空话：
  - SLSA（Google/OpenSSF 2021）+ SBOM（NTIA/EO 14028）+ MITRE T1195；
  - 最小权限（Saltzer & Schroeder CACM 1975）+ 能力安全（Dennis & Van Horn 1966）+ NIST SP 800-53 AC-6；
  - 依赖混淆（Birsan 2021）+ CWE-798/829/506 + OWASP LLM01 + MITRE ATT&CK T1059。
- 红线规则与理论一一对应（提示注入↔LLM01、硬编码密钥↔CWE-798、远程执行↔CWE-829/T1059）。

## R · 工程可靠 — 5.0 / 5

- 纯 Python 标准库，零外部依赖，装了即跑。
- 退出码文档化 0/1/2/3/4，与 agent 编排语义对齐（4=已拦截）。
- preflight 集中校验（缺路径 / 路径非法立即中文报错退出 1）。
- 规则库外置 `resources/rules.json`，改规则不动代码。
- 扫描对二进制/超大文件做了 safe-skip，不会因一个坏文件崩溃。

## A · 可用易用 — 5.0 / 5

- CLI 一行跑完主流程：`python guard.py review <目录>` 即出报告。
- 五个子命令职责清晰（review/scan/rules/ledger/version），无隐藏参数。
- 输出双语友好：终端可读报告 + `--json` 机读，报告含机器可读 JSON 尾块供 ledger 聚合。
- 规则可改、可解释（每条红线带 id/类别/严重度）。

## C · 闭环完整 — 5.0 / 5

- 完整五步闭环：**检测（scan）→ 判定（infer_verdict 优先级链）→ 拦截（退出码 4）→ 报告（verdict_report.md）→ 记账（ledger 价值量化）**。
- 判定链按严重度优先级收敛，不取平均——避免一个高危被多个低危稀释。
- 价值量化把"没发生的事故"折算成可感知数字（避免 N 小时事故响应），闭环最后一环不缺。

## E · 证据可验 — 5.0 / 5

- 每次审查留下实体证据 `verdict_report.md`（可重跑、可存档、含机器可读尾块）。
- `ledger` 聚合多份报告生成 `guard-ledger.md`，证明控制有效性的标准安全运营做法。
- 冒烟测试 `smoke_guard_skill.py` 覆盖空目录、坏参数、干净包、恶意包、判定链、价值账本、版本三处一致，全 PASS。

## 总评

**T5 / R5 / A5 / C5 / E5 = 5.0 / 5**

原创量化点：供应链信任指数（0-100，基准 100 减严重度扣分）与四级判定优先级链——把"这个包安不安全"从感觉变成可统计的分数与等级。相对 self 系列 4.8 基准，本包在理论厚度与证据闭环上均达标，作为 guard 系列旗舰，目标 4.8+。
