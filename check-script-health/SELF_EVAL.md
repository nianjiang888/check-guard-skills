# SELF_EVAL（TRACE 5D 自评）

评分维度：T 正确性 / R 鲁棒性 / A 适用性 / C 清晰度 / E 工程性（各 1–5 分）

## T 正确性（T=4.5）
- 七维度评分与完播健康指数计算闭环：每维度 = 100 − 该维度命中权重和（封顶 0），健康指数 = 各维度按权重加权均值；合规红线强制压到 40 以下。逻辑自洽。
- 四档样例引擎实跑，判定块与维度分一致，无前后矛盾。
- 扣分点：合规正则的边界仍可能漏判（如「全网最低」类变体未穷尽），属规则集可扩展问题，非引擎错误。

## R 鲁棒性（R=4.5）
- 规则加载期逐条正则合法性校验，坏正则跳过不崩（继承 #2 工程缺口修复）。
- 非文本/二进制文件自动跳过；示例白名单（test_/example/sample 前缀）跳过，避免样例污染。
- 缺文件、坏路径、空文件均有明确退出码（2/3）。
- 扣分点：超长单文件（>数 MB）未设上限（#2 有 8MB 上限，本包未加），极端大文件可能偏慢。

## A 适用性（A=4.0）
- 覆盖短视频脚本最常见的七类硬伤，对口播稿、带货稿、知识口播、剧情脚本均有意义。
- 局限（诚实声明）：① 流量平台规则不公开，指数不预测播放量；② 不读视频画面/配音，只体检文本稿；③ 多语种/中英混排未专门优化（英文触发词仅用于匹配，正文英文不影响评分）；④ 不区分平台差异（抖音/视频号/小红书社区规范不同，合规维度取最大公约数）。
- 适用边界已在 SKILL.md 与 FAQ 明确写出。

## C 清晰度（C=4.5）
- SKILL.md 含中文/口语/英文三段触发词、一句话功能、七维度表格、边界、用法、免费付费说明。
- 报告含判定 + 健康指数 + 七维度分表 + 发现清单（严重度/规则/维度/说明/建议）+ 机器可读判定块，可读性与可消费性兼具。
- 扣分点：维度权重（hook/retention/compliance 各 0.20）为经验设定，未做用户调研校准，已在 methodology 注明。

## E 工程性（E=5.0）
- 纯标准库，零第三方依赖，任何 Python 3.8+ 环境可直接跑。
- 命令集统一（scan/rules/ledger/version），与 check 系列兄弟一致；冒烟自检 24 项断言覆盖四档判定、维度自洽、红线、规则加载。
- 样例与报告分离（script-demo-* 输入 / sample-scan-* 输出），白名单不互扰。
- A2M 付费三件套以 frontmatter 注释预留，改收费零改动规则与引擎。

**均值：(4.5+4.5+4.0+4.5+5.0)/5 = 4.5**

## 已知缺口（诚实列出）
1. 单文件大小未做上限（兄弟包有 8MB 上限）。
2. 合规正则未穷尽全部极限词变体（如「全网最低」「销量王」）。
3. 维度权重为经验值，未做数据校准。
4. 未做跨平台规范分化（抖音/视频号/小红书）。
5. 真实爆款/废稿语料未做大规模回归验证（合成样例只证逻辑正确）——收费前建议补一批真实脚本批次测试。

## 反哺沉淀
- 「维度评分 = 100 − 该维度权重和」的局部健康度算法，可复用到任何多维度体检类技能（区别于 #1/#2 的全局暴露指数）。
- 合规红线强制压分机制，可复用到任何含「一票否决」维度的检查器。
- 多档样例 + 维度分自洽断言，是防止评分引擎回归的有效闸门。
