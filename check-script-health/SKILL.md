# check-script-health 是什么

check-script-health 是短视频脚本发布前的「完播健康护栏」。不是代写脚本（那是创作的事），也不是平台流量预测（平台算法不公开、也没人能拍胸脯保证爆），而是更日常的「脚本 lint」——把稿子开拍/发布前过一遍，看看最容易被划走、被限流、被判定违规的硬伤在哪：开头三秒没有钩子、中段平铺直叙留不住人、水词太多稀释信息、结尾没有引导、用了广告法极限词、通篇书面腔不像说话。

一条脚本"感觉还行"往往只是没被认真体检过。开头三秒决定了绝大多数人的去留，极限词可能直接触发限流或下架，全程书面腔观众根本听不进去。check-script-health 要做的，是把"发布前最后过一遍"变成可量化、可复跑、留证据的静态体检。

## 能做什么

七维度打分，对应一条能跑完的短视频该有的骨架：

| 维度 | 查什么 | 说明 |
|---|---|---|
| hook 开头钩子 | 前 3 秒是否有强钩子、是否用「你」对话观众 | 没有钩子，前 3 秒就被划走，后面再好也白搭 |
| retention 完播留人 | 中段是否有反转/反差/悬念/冲突 | 平铺直叙最容易在中途流失，要让观众想看后面 |
| density 信息密度 | 水词/车轱辘话多少、有没有具体数字、篇幅与时长是否匹配 | 短视频每字都该有信息，注水会被判低质 |
| cta 互动引导 | 结尾是否有行动号召、是否抛互动问题 | 完播流量要沉淀成点赞关注评论，否则白跑 |
| compliance 合规安全 | 广告法极限词、疗效承诺、私域引流、收益夸大 | 任意一项命中即合规红线，可能限流/下架/封号 |
| emotion 情绪共鸣 | 是否有真实可共鸣的情绪点 | 没情绪就没人想转给同处境的人 |
| spoken 口语表达 | 是否书面腔重、是否有超长难句 | 像聊天不像念稿，口播才顺、才有人听 |

算「完播健康指数(0-100)」与各维度得分，出逐条可修正建议，退出码 0/1/2/3/4。

## 边界（重要）

- 只读纯文本（.md / .txt）。脚本写在 Word、备忘录截图、飞书文档里的，先转成纯文本再扫，否则什么都扫不出来。
- **读不到平台规则和流量数据**，因此不知道本次的具体推荐机制、同类爆款基线。体检基于通用创作方法论与大量爆款拆解经验，不是平台官方标准，也不预测播放量。
- 合规维度按国内广告法常见雷区与平台社区规范常识设计，不能替代法律顾问，命中红线只提示风险不替代判断。
- 不修改脚本、不拦截发布、不承诺 100% 爆款。命中不等于必然限流，未命中也不保证上热门——这是发布前的体检，不是爆款保险。

## 怎么用

```
python scripts/check.py scan <脚本文件或目录> [报告输出路径]
python scripts/check.py rules                  列出全部规则
python scripts/check.py ledger <脚本目录>       输出 JSON，供脚本消费
python scripts/check.py version
python scripts/smoke_test.py                    四档样例隔离实跑自检
```

扫描结束输出判定（优秀 / 良好 / 一般 / 偏弱 / 红线）、完播健康指数、七维度评分、可修正与不可修正数量、发现项数，报告末尾附机器可读的 `SCRIPT_HEALTH_RESULT {...}` 判定块。

退出码：0 干净，1 有命中，2 输入输出错误，3 命令写错，4 命中合规红线（极限词/疗效承诺/私域引流/收益夸大）。
