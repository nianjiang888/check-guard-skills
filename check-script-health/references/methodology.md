# 短视频脚本体检评分 · 方法论说明

本文件说明 check-script-health 的评分依据与设计边界。先说清楚一点：短视频平台的推荐算法、完播率权重、限流规则均不公开，也没有任何机构发布「脚本健康度国标」。因此这里的评分**不是平台官方标准，也不预测播放量**，而是基于公开可见的创作方法论与大量爆款/废稿拆解经验，把"一条能跑完的短视频该有的骨架"固化成可量化、可复跑的静态检查。

## 七维度从哪来

一条短视频从被刷到、到看完、到互动，链路大致是：被封面/开头留住 → 中段不想划走 → 信息不水 → 结尾被引导互动 → 不踩合规雷 → 让人有共鸣 → 听起来像人说人话。把这七步映射成七个维度：

| 维度 | 对应链路环节 | 命中后果 |
|---|---|---|
| 开头钩子 hook | 前 3 秒去留 | 没钩子直接被划走，后面再好也白搭 |
| 完播留人 retention | 中段留存 | 平铺直叙，中途流失 |
| 信息密度 density | 单位时间价值 | 水词/车轱辘话被算法判低质 |
| 互动引导 cta | 流量沉淀 | 完播不转互动，推流雪球滚不起来 |
| 合规安全 compliance | 不被限流下架 | 极限词/疗效/私域/夸大，可能直接限流或封号 |
| 情绪共鸣 emotion | 转发意愿 | 没情绪没人想转给同处境的人 |
| 口语表达 spoken | 听感与完播 | 书面腔/长难句，口播气短、观众走神 |

## 评分算法

- 每条规则带严重度权重：极端 100 / 高 40 / 中 12 / 低 3。
- 每个维度得分 = `max(0, 100 − 该维度命中权重之和)`。即只扣该维度内部的扣分，不因为别的维度差而连坐——这样能看出"到底哪块塌了"。
- 完播健康指数 = 七维度按权重加权均值（hook 0.20 / retention 0.15 / density 0.12 / cta 0.13 / compliance 0.20 / emotion 0.10 / spoken 0.10）。compliance 权重最高，因为它是"一票否决"性质的红线。
- **合规红线**：任意极端规则命中，健康指数强制压到 40 以下并判「红线」，退出码 4。理由：内容违规的后果（限流/下架/封号）远大于结构瑕疵，必须一眼可见。

权重是经验值，不是回归拟合结果。不同赛道（知识口播 vs 剧情 vs 带货）合理权重会有差异，当前取通用最大公约数。

## 各特殊体检项的判定逻辑

- **开头钩子**：取正文前 90 字，匹配反常识/冲突/悬念/痛点提问/利益承诺/「你」对话等钩子信号；前 120 字再单独检查是否用「你/您」拉近距离。
- **完播留人**：全文检索反转/反差/悬念/反直觉/「你以为…其实」等留人信号，全无则判缺失。
- **信息密度**：① 水词密度——统计口头禅（啊/呢/然后/就是说/其实吧…）出现频率，过高则扣分；② 车轱辘话——按标点拆句后找重复出现的 4 字以上短语；③ 篇幅-时长——若脚本含「时长：N秒」标注则按 N×3~4.5 字估算合理篇幅，偏离过大扣分，无标注按默认 60 秒。
- **互动引导**：取正文末 120 字检索点赞/关注/评论/转发/下期等 CTA 信号；另查是否抛了互动提问。
- **合规安全**：四组正则——广告法极限词、疗效绝对承诺、私域引流、收益夸大。正则做了词边界处理（如「第一笔/第一步」不误判为极限词）。
- **情绪共鸣**：全文检索扎心/破防/无奈/你有没有…等共鸣信号，全无则判缺失。
- **口语表达**：检测书面连词（综上所述/然而/基于/鉴于/值得注意的是…）与超长难句（单句>45 字无标点）。

## 边界（务必读）

1. 只读纯文本，不读画面、不读配音、不读数据。
2. 不预测播放量，不保证爆款，只是"发布前排雷 + 完播骨架体检"。
3. 合规维度按国内广告法与主流平台社区规范常识设计，不能替代法律顾问。
4. 维度权重、阈值均为经验设定，欢迎基于真实数据校准。
