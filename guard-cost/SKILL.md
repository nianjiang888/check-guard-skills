# guard-cost API 花费熔断引擎

## 一、这是什么

guard-cost 是 guard 安全护栏系列的第 5 个独立成员，定位是「API 花费熔断（成本防护）」。rm -rf 会删库，无护栏的付费 API 调用会"删钱"——循环里调大模型、无限重试、没预算上限、没熔断，月底账单能炸。它和系列其他成员平行独立，各自守一个专业安全域，不挂古人 IP、不做流水线叙事。

它做的是：在代码跑起来之前，先扫一遍这些成本雷区，算一笔「花费暴露指数」，再用 `cap` 干跑一笔投影花费，让你在按回车之前就知道会花多少。

## 二、能做什么 / 不能做什么

能做的：

- 检测七层成本雷区：无界循环（while True / for / map 内调付费 API）、预算缺失（无 max_tokens / 预算常量）、限速/熔断缺失、重试失控（无上限重试）、高单价模型（gpt-4 / o1 / claude-opus 无降级）、密钥硬编码（盗刷风险）、安全变体（预算常量 / 熔断装饰器 / 限速中间件，仅作鼓励信号）。
- `cap` 子命令对 `model:次数xtoken` 简写按参考单价做花费投影，或对目录扫描算花费暴露指数，干跑、不拦请求。
- 把「拦下的先兆」折算成可感知数字（避免的止损工时），并聚合成价值账本。

不能做的（诚实边界）：

- 不实际拦截任何请求、不代你设预算——决策权始终在人。
- 不感知运行时动态调用频次；只在被扫描的代码文本里看得到模式。
- 不保证 100% 拦住所有超支，只是多层防御中的一层（需配预算、限流、熔断、计量）。
- 单价仅为参考估算，真实花费以服务商账单为准。

## 三、怎么用

引擎在 `scripts/guard.py`，纯标准库、零依赖、可重跑。五个子命令：

```
python scripts/guard.py scan  <目录>                  # 扫描并出 cost_report.md，高/极端退出码 4
python scripts/guard.py cap   <路径 | model:次数xtoken> # 花费投影：路径模式或简写模式
python scripts/guard.py rules                          # 列出全部成本风险规则库
python scripts/guard.py ledger [目录]                   # 聚合多份报告生成价值账本
python scripts/guard.py version                        # 打印引擎版本
```

典型用法：上线前 `scan` 一遍含大模型调用的目录，看报告里的花费暴露指数；对一个具体调用用 `cap "gpt-4o:10000x2000"` 直接看会花多少；日常把若干 `cost_report.md` 用 `ledger` 聚合成团队成本防护账本。

## 四、判定与量化（原创点）

判定走**优先级链**而非平均：极端 > 高 > 中 > 低。只要命中一条极端规则（如 while True 内调付费 API），整体就是极端。

两个量化指标：

- **花费暴露指数（0-100）**：命中严重度权重（极端 100 / 高 40 / 中 12 / 低 3）累加封顶。
- **安全控制价值量化**：拦下后估算避免的止损工时（极端 8h / 高 4h / 中 1h / 低 0h），把「没发生的超支」变成可感知数字。

退出码：0 通过 / 1 参数错 / 2 IO 错 / 3 未知命令 / 4 已拦截（高/极端）。第 4 态是 guard 系列的统一约定。

## 五、理论底座

- **熔断器模式**（Nygard 2007）：失败率超阈值就自动断开，避免雪崩式烧钱。
- **令牌桶**（Turner 1986）：固定速率发令牌，把「无限调用」变「有限配额」。
- **控制论视角**：花费是受控变量，预算=设定点、熔断=执行器、计量=反馈；无反馈系统必然发散。
- **设计立场**：看清账单后果再决定，不硬禁止。硬禁止会逼出绕过，那更糟。

详细论证见 `references/` 下三篇：`circuit-breaker.md`、`cost-control-theory.md`、`defense-stance.md`。规则与单价数据见 `resources/`：`rules.json`、`cost-models.json`、`cost-domains.json`。

## 六、产物与退出码

- `cost_report.md`：单次扫描/投影产物，含判定、命中清单、花费暴露指数、价值量化，JSON 尾附结构化结果。
- `cost_cap_report.md`：简写投影产物，含模型/次数/token/投影花费/建议。
- `guard-ledger.md`：多份报告聚合后的安全控制价值账本。

报告只写本地工作目录，不含任何凭据或网络地址。误报会杀死产品，故复合规则要求「确实调了付费 API」才提示、缺护栏只报中危、安全变体只作鼓励信号不当命中。
