# guard-secret · 密钥 / 凭据泄露扫描

## 一、干什么

guard-secret 是**提交 / 发布之前**的一道密钥体检。它做三件事：

1. **三层检测**：正则匹配已知密钥格式（精度）→ 香农熵捕捉任意高随机串（召回）→ 上下文与白名单降误报。
2. **判定 + 出报告**：给出低 / 中 / 高 / 极端四级风险判定，生成可存档的 `secret_report.md`，逐条标注密钥类型、置信度、是否疑似已泄露、要不要轮换。
3. **折算价值**：把"拦下的泄露事故"折算成可感知数字，累积成安全控制价值账本。

定位上，它是代码进版本库、进镜像、进公开仓库之前的**守门员**——不是运行时的密钥管理服务，而是提交前的静态扫描。

## 二、主动触发

当用户准备 `git commit`、打发布包、或把配置/代码交给别人之前，主动建议先跑一轮 guard-secret 扫描；当用户提到"这串是不是密码 / 仓库里有没有密钥 / 别把密钥传上去"时，直接调用本技能做扫描，而不是凭肉眼翻代码。

## 三、理论地图

- **香农熵与密钥检测**（references/shannon-entropy.md）：信息熵 H = −Σ p(x)·log₂p(x) 如何度量"随机程度"，以及 hex>4.0 / base64>5.5 / 通用>4.5 三个阈值的来历。
- **三层检测管线与诚实边界**（references/secret-detection-pipeline.md）：为什么没有单种方法能挑大梁，正则/熵/上下文如何互补；与 CWE-798 对齐；"删行没用、必须轮换"的关键纠正。

## 四、快速上手

```bash
# 扫描目录，生成 secret_report.md（高/极端会退出码 4 拦截）
python guard.py scan <目录>

# 查看正则规则库与熵阈值
python guard.py rules

# 聚合多份扫描报告，生成安全控制价值账本
python guard.py ledger <目录>
```

## 五、子命令速查

| 子命令 | 作用 | 退出码要点 |
|---|---|---|
| `scan <目录>` | 三层扫描 + 出报告 | 高/极端 → 4（已拦截） |
| `rules` | 打印正则规则库与熵阈值 | 0 |
| `ledger <目录>` | 聚合报告生成价值账本 | 0 |
| `version` | 打印引擎版本 | 0 |

参数错 → 1，IO/运行错 → 2，未知子命令 → 3，已拦截 → 4。

## 六、边界声明

- **能做的**：静态密钥/凭据扫描、输出可存档报告、标注疑似已泄露并给轮换建议、折算拦截价值。
- **不能做的**：运行时密钥管理（如 Vault）、动态内存/流量中密钥捕获、保证 100% 拦住所有泄露（学界共识无单点银弹，本工具三层组合目标精度 90–95%）。
- **隐私**：扫描全程在本地进行，不向外发送被扫目录的任何内容。
