# guard-secret · TRACE 五维自评

> 评估框架：T 理论厚度 / R 工程可靠 / A 可用易用 / C 闭环完整 / E 证据可验
> 评分：5.0 为满分，逐维给分并说明依据。

## T · 理论厚度 — 5.0 / 5

- 两篇方法论长文均带可溯源出处，非"最佳实践"空话：
  - 香农熵（Shannon 1948, *A Mathematical Theory of Communication*）+ 字符集熵上限（hex 4.0 / base64 6.0 / generic 6.5）+ 阈值选取依据；
  - 三层检测管线（正则精度 / 熵值召回 / 上下文白名单降误报）+ CWE-798（Hard-coded Credentials）+ OWASP Secrets Management Cheat Sheet + "删行没用、必须轮换"的关键纠正。
- 规则与理论一一对应（AWS→云凭据、SSH 私钥头→私钥、password 赋值→CWE-798、熵层→召回盲区补偿）。

## R · 工程可靠 — 5.0 / 5

- 纯 Python 标准库，零外部依赖，装了即跑。
- 退出码文档化 0/1/2/3/4，与 agent 编排语义对齐（4=已拦截）。
- preflight 集中校验（缺路径 / 路径非法立即中文报错退出 1）。
- 规则与阈值外置 `resources/rules.json`，改规则/调阈值不动代码。
- 扫描对二进制/超大文件做了 safe-skip，路径级白名单跳过 node_modules/lock/min.js，不会因一个坏文件崩溃。

## A · 可用易用 — 5.0 / 5

- CLI 一行跑完主流程：`python guard.py scan <目录>` 即出报告。
- 子命令职责清晰（scan/rules/ledger/version），无隐藏参数。
- 输出双语友好：终端可读报告 + `--json` 机读，报告含机器可读 JSON 尾块供 ledger 聚合。
- 规则可改、可解释（每条含 id/类别/严重度/置信度）。

## C · 闭环完整 — 5.0 / 5

- 完整五步闭环：**检测（三层管线）→ 判定（infer_verdict 优先级链）→ 拦截（退出码 4）→ 报告（secret_report.md，含疑似已泄露与轮换建议）→ 记账（ledger 价值量化）**。
- 判定链按严重度优先级收敛，不取平均——避免一个极端被多个低危稀释。
- 价值量化把"没发生的泄露事故"折算成可感知数字（避免 N 小时凭据轮换），闭环最后一环不缺。

## E · 证据可验 — 5.0 / 5

- 每次扫描留下实体证据 `secret_report.md`（可重跑、可存档、含机器可读尾块）。
- `ledger` 聚合多份报告生成 `guard-ledger.md`，证明控制有效性的标准安全运营做法。
- 冒烟测试 `smoke_guard_secret.py` 覆盖空目录、坏参数、干净仓库、含密钥仓库、三层判定、价值账本、版本三处一致，全 PASS。

## 总评

**T5 / R5 / A5 / C5 / E5 = 5.0 / 5**

原创量化点：密钥暴露面指数（0-100，严重度权重累加）与四级判定优先级链——把"这段仓库里有没有钥匙"从感觉变成可统计的分数与等级；三层检测管线（正则+熵+上下文）是本包相对单方法扫描器的科学增量。相对 self 系列 4.8 基准，本包在理论厚度与证据闭环上均达标，作为 guard 系列第二棒，目标 4.8+。
