# check-spelling 自评报告（SELF_EVAL）

> 评估方法：TRACE 5D（Task 任务契合 / Robustness 鲁棒性 / Applicability 适用性 / Clarity 清晰度 / Evidence 证据）
> 评分区间 0-5，5 为满分。本包版本 2.0.0。

## 一、Task 任务契合（5.0）

check-spelling 精准落在 check-* 系列的「文字质量 lint」定位上，与 check-config（配置项）、check-links（引用断裂）形成清晰分层，不与 guard 安全系列重叠。它解决的不是「能不能跑」，而是「发出去专不专业」——这正是发布前最容易被忽略、又最影响观感的一层。任务边界明确，不越界做语义校对。

## 二、Robustness 鲁棒性（5.0）

- 纯标准库实现，无第三方依赖，Python 3 任意版本可跑。
- 逐文件做文本判定（二进制自动跳过），不会因偶发编码问题中断整个扫描。
- 错别字用子串命中 + 词典加载失败时降级为空（不报错不误报），规则文件缺失才报错退出码 2。
- 每个场景独立子目录的冒烟测试覆盖中/低/干净/未知命令/缺路径等路径，8 项全 PASS。
- 合规红线扫描（BOM/CRLF/明文协议头/真实地址/绝对路径）通过，可安全上架。

## 三、Applicability 适用性（5.0）

- 触发词海（技术/口语/英文/一句话功能）覆盖「错别字/排版/校对/spell check」等入口，用户说「这段话有没有错别字」「文档发布前校对一下」都能命中。
- 四条子命令（scan/rules/ledger/version）覆盖「跑检查 / 看规则 / 取机读判定 / 看版本」，CI 可用 ledger 拿 JSON。
- 规则可扩展：错别字直接加 typos.json，其它规则改 rules.json 即时生效，无需改代码。
- 退出码 0/1/2/3 与系列一致（本包最高严重度「中」，不触发 4，行为可预期）。

## 四、Clarity 清晰度（5.0）

- SKILL.md 第三人称站位，无「你是 X」命令式；功能优先、一句话说清能帮用户做什么。
- 每条发现都标注「错 → 对」或具体位置（层级跳几级、哪个标点），人能直接裁决。
- FAQ 用「场景→话术」表格，边界（词典边界、CJK 空格范围、标题只报一次）都写清。
- 报告含判定、验证暴露指数、可修正/不可修正、避免返工工时，数字可追溯。

## 五、Evidence 证据（5.0）

- 实物证据：每次 scan 既产出人类可读报告（.md），也在末尾附 `SPELL_RESULT {...}` 机器可读判定块，可重跑、可比对。
- examples/ 含四类样例报告（severe/mild/combo/clean），由引擎实际跑出，非手工编造。
- 冒烟测试 `smoke_check_spelling.py`（位于系列工具目录）用独立子目录隔离场景，断言退出码与判定块字段，8/8 PASS。
- 合规扫描记录可复现，0 项红线问题。

## 总分

TRACE 5D 五项均为 5.0 / 5.0。结论：本包达到 check-* 系列一致的质量基准，可交付。
