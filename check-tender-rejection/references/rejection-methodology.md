# 废标自查方法论：为什么这么查

## 一、废标是怎么发生的

废标不是评审时"打分低"，而是**在打分之前就被判定出局**。评审流程分三道闸：

1. **资格性审查** —— 资质、证照、保证金，缺一项直接出局，后续内容写得再好也不看
2. **形式性审查** —— 签字盖章、有效期、密封、份数，程序不合即废
3. **符合性/响应性审查** —— 是否实质性响应招标文件的强制要求，关键条款偏离即废

这三道闸的共同点是：**都是"有或无"的二值判断，没有中间分**。这决定了废标检查天然适合做成静态 lint——模式命中即报，不需要打分模型。

## 二、为什么分层

本包把规则分成五层，对应上面三道闸加两个补充维度：

| 层 | 对应评审闸口 | 特征 | 典型严重度 |
|---|---|---|---|
| qualification | 资格性审查 | 缺了就出局，多数补不回来 | 高 |
| formality | 形式性审查 | 可补救，但截止时间前必须补上 | 高 |
| consistency | 符合性审查 | 内部矛盾，需人工核对 | 中—高 |
| format | 观感与低级错误 | 部分招标文件列废标条款 | 低—中 |
| technical | 响应性审查 | 关键条款偏离即废 | 中—高 |

分层的价值不在好看，而在**报告可读性**：投标人拿到报告，能一眼看出"哪些是必须马上补的硬伤，哪些是有则改之的观感问题"。

## 三、三种判定机制与各自的分寸

### 1. missing_any：同义词全未检出才报

这是本包最关键的设计。标书里同一个东西有 N 种叫法：

- 财务材料 = 财务报表 / 审计报告 / 资信证明
- 项目经理证 = 注册建造师 / 建造师注册证 / 项目经理证书
- 授权文件 = 授权委托书 / 法人授权 / 法定代表人授权书

如果按"任一叫法没出现就报缺失"处理，一份写了"审计报告"的合规标书会被误报成"缺财务报表"。**误报会直接杀死这类工具**——用户被骗两次就再也不用了。

所以 missing_any 的语义是：**terms 是同一事物的多种叫法（OR 关系），全部叫法都没检出，才算真缺失**。

### 2. regex：正向危险信号

有些雷区不能用"缺失"表达，只能用"出现了不该出现的表述"：

- "超出/高于/高出/超过……限价" → 报价超限，必废
- "偏离……要求""未能响应""无法满足……要求" → 关键条款不响应
- "证书……已过期""有效期……已过" → 证书无效
- "待盖章""未签字""此处盖章" → 编制过程中的遗留标记

这类规则的风险是**正则写得太宽会乱报**。本包的原则是：宁可漏报，不可误报。拿不准的表述不进规则库。

### 3. 计算型：date / amount / pagegap / deadline

纯正则做不了的交给计算：

- `deadline`：解析开工/竣工的**具体日期并真正比较大小**，只在确实倒挂时才报。如果只判断"两个字段都存在"就报，任何正常标书都会被误判。
- `date` / `amount`：只在数量超过阈值（默认 3 / 4 处）时才提示"需人工核对"。一两处日期或金额是正常标书的常态，提示了就是噪音。
- `pagegap`：解析页码序列，真发现跳号才报。

## 四、量化口径是怎么来的

**废标风险指数（0-100）**：把每条命中的严重度换算成权重后累加，上限截断到 100。

| 严重度 | 权重 | 含义 |
|---|---|---|
| 极端 | 100 | 必废标项（如报价超限），命中即满分 |
| 高 | 40 | 资格或形式硬伤，两三条即逼近满分 |
| 中 | 12 | 需复核的一致性或响应性问题 |
| 低 | 3 | 观感与低级错误 |

**判定**取命中项中的最高严重度：极端→极端，无命中→通过。这样"报价超限"这种一票否决项能直接把整份标书判成极端，不会被一堆低危项稀释。

**预计避免损失**：把严重度换算成金额基数后累加。

| 严重度 | 基数 |
|---|---|
| 极端 | ¥500,000 |
| 高 | ¥100,000 |
| 中 | ¥50,000 |
| 低 | ¥10,000 |

这个数字不是精算结果，是**给付费用户一个直观的量级感**：一次废标意味着保证金损失、团队一个月的工作归零、以及这个标的彻底错过。¥1.5 的检查费对标几十万的潜在损失，付费理由不靠说服，靠这个对比。

## 五、诚实的能力边界

必须说清楚本包**做不到**什么，否则就是骗人：

1. **看不懂扫描件**。本包读的是文本（.md/.txt），PDF 扫描件需先 OCR。
2. **读不了招标文件**。本包不知道你这次招标的具体要求（限价多少、资质几级、有效期几天），只能查通用雷区。涉及具体数字的比对，报告会提示"需人工核"。
3. **判不了隐形排他条款**。那些量身定制的排他性要求，需要专业法务和招标顾问。
4. **不保证不废标**。规则命中不等于必然废标，未命中也不保证中标。本包是提交前的最后一道体检，不是中标保险。

把这四条写进 SKILL.md 的边界章节，比藏起来更有助于建立信任。
