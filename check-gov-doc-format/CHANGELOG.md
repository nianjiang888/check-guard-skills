# CHANGELOG

## v1.0.0（2026-09-06）

首版发布。

### 规则库

- 45 条规则全部落库，每条带权威依据条款号：
  - 22 条自动判定：版头 5（发文字号六角括号、年份全称、顺序号虚位/"第"字、签发人）、主体 10（层次序数标点、成文日期阿拉伯数字不编虚位、附件说明标点、附注圆括号、标题书名号限定标题场景）、版记 3（抄送句号与全角冒号、印发日期"印发"收尾）、通用 2（非法定文种、主题词残留）、文种 2（会议纪要冗余、此页无正文）
  - 23 条人工核对项：字体字号、页边距、版心尺寸、行数字数、印章位置、页码等排版层项，逐项附国标标准值；其中 8 条按文种/要素条件化输出（信函、命令、纪要、签发人、附件、抄送、印发）
- 权威基座：GB/T 9704-2012（2012-07-01 实施，现行有效）+ 中办发〔2012〕14号《党政机关公文处理工作条例》（15 法定文种、18 格式要素），条款对照见 references/gb9704-methodology.md

### 引擎

- 复用 check 系列骨架，纯标准库零依赖；四种判定机制（regex 命中 / req 组合 / absent 缺失 / missing_any 同义词组全缺）
- 相对 check-tender-rejection v1.0.0 的两处工程改进：
  1. 规则加载期正则逐条编译校验，非法正则打印规则 id 并跳过（修复 #1 包自评 R 维扣分项）
  2. 单文件 8 MB 读取上限，超限跳过并警告
- 报告工时估算标注"量级估算，按严重度基数累加，非精算"（修复 #1 包自评 C 维扣分项）
- 本域不设"极端"判定：公文格式问题可重排补救，无标书语境的一票否决量级，SEV_WEIGHT 保留"极端"仅作字典兼容

### 开发过程中修正的规则设计问题

1. 印发日期规则初版会误伤独立成行的成文日期，改为检出"版记块缺「年月日印发」收尾"
2. 附注规则初版逻辑写反，改为检出"标了「附注」二字"（国标是直接加圆括号）
3. 标题书名号规则初版不区分标题与正文（正文引用文件加书名号是正确的），限定为只命中标题特征
4. 人工清单初版无条件全量输出，对普通通知会列出一堆信函格式要求，改为条件化

### 样例

- 四份样例公文（govdoc-demo-clean/mid/high/combo）+ 四份引擎实跑报告：
  - clean：通过，0/100，0 发现项（零误报验证）
  - mid：中，36/100，3 发现项
  - high：高，100/100，7 发现项
  - combo：高，100/100，8 发现项
- 样例文件命名避开引擎白名单（#1 包教训：sample 前缀会被跳过）

### 已知边界

- 只读 .md/.txt，Word/WPS 需先转文本
- 排版层信息（字体、页边距、印章）纯文本不存在，诚实进人工清单，不假装自动判定
- 党的机关专用版头、军队公文、地方细则未覆盖（详见 SELF_EVAL A 维）
