# check-gov-doc-format

公文印发前的格式国标终检。依据 GB/T 9704-2012《党政机关公文格式》与中办发〔2012〕14号《党政机关公文处理工作条例》，对纯文本公文做 22 项自动格式判定 + 23 项人工核对清单，算格式违规指数并逐条引用国标条款号出整改建议。

## 快速开始

```bash
# 扫描单个文件并生成报告
python scripts/check.py scan 通知.md 报告.md

# 扫描目录
python scripts/check.py scan ./公文目录/ 报告.md

# 列出全部规则（含国标条款号）
python scripts/check.py rules

# 自检
python scripts/smoke_test.py
```

## 能查什么（自动，22 条）

- **版头**：发文字号用了中括号不是六角括号〔〕、年份没写全称、顺序号编了虚位（001）或加了"第"、上行文缺签发人
- **主体**：层次序数"1."写成"1、"、成文日期写汉字或月日编虚位、附件说明名称后加了标点、"附件"后没写全角冒号、附注标了"附注"二字（国标是直接加圆括号）、标题给方案/计划加书名号
- **版记**：抄送末尾没写句号、"抄送"后没写全角冒号、版记块缺"印发"收尾
- **文种**：用了"申请/汇报/说明"等非法定文种（15 种法定文种见《条例》第八条）、旧模板残留"主题词"（2012 版已删除该要素）、"会议纪要"冗余写法

## 查什么靠人（23 项，带标准值）

字体字号（标题 2 号小标宋、正文 3 号仿宋）、页边距（上 37mm 下 35mm 左 28mm 右 26mm）、版心 156mm×225mm、每面 22 行×28 字、印章下压署名与成文日期、成文日期右空四字、页码编排——这些是排版层信息，纯文本里不存在，本包不假装能查，而是逐项列出国标标准值供对照原件核。信函/命令/纪要三类特定格式清单按文种条件化输出，普通公文不会被无关项打扰。

## 设计原则

每条规则带 `basis` 条款号（如 GB/T 9704-2012 7.3.5.3），报告逐条显示，可直接拿去和办公室核。条款来源与判定语义见 `references/gb9704-methodology.md`。规则库 45 条全部可正则编译校验（见 CHANGELOG v1.0.0）。

## 定位

check 系列成员之一，专注"党政机关公文格式国标合规"。错别字归 check-spelling，引用断裂归 check-links，标书废标归 check-tender-rejection。
