## 二、人工核对清单
以下为国标明确规定、但纯文本无法自动判定的项（字体字号、页边距、印章位置等），需对照原件逐一核对：
| 层 | 国标条款 | 核对项 | 标准值 |
|---|---|---|---|
| 版头 | GB/T 9704-2012 7.2.7 | 版头红色分隔线位置需核对（发文字号之下 4mm） | 发文字号之下 4mm，与版心等宽，红色 |
| 版心 | GB/T 9704-2012 5.2.1 | 页边距与版心尺寸需核对 | 天头（上白边）37mm±1mm，订口（左白边）28mm±1mm，版心 156mm×225mm |
| 版心 | GB/T 9704-2012 5.2.2 | 正文字体字号需核对 | 3 号仿宋体字（_GB2312 或 仿宋），特定情况可作适当调整 |
| 版心 | GB/T 9704-2012 5.2.3 | 每面行数与每行字数需核对 | 一般每面排 22 行，每行排 28 个字，并撑满版心 |
| 版心 | GB/T 9704-2012 7.3.1 | 标题字体字号需核对 | 2 号小标宋体字，编排于红色分隔线下空二行，分一行或多行居中排布 |
| 版心 | GB/T 9704-2012 7.3.3 | 结构层次序数的字体需核对 | 第一层「一、」用黑体字，第二层「（一）」用楷体字，第三层「1.」和第四层「（1）」用仿宋体字 |
| 版心 | GB/T 9704-2012 7.3.3 | 正文段落缩进需核对 | 每个自然段左空二字，回行顶格 |
| 版心 | GB/T 9704-2012 7.2.5 | 发文字号编排位置需核对 | 编排在发文机关标志下空二行位置，居中排布；上行文居左空一字编排 |
| 版心 | GB/T 9704-2012 7.2.4 | 发文机关标志位置与颜色需核对 | 居中排布，上边缘至版心上边缘为 35mm，推荐使用小标宋体字，颜色为红色 |

| 版心 | GB/T 9704-2012 7.3.4 | 附件说明缩进需核对 | 正文下空一行左空二字编排「附件」，后标全角冒号和附件名称 |
| 版心 | GB/T 9704-2012 7.3.5.1 | 发文机关署名与成文日期位置需核对 | 成文日期一般右空四字编排，发文机关署名以成文日期为准居中编排在其上方 |
| 版心 | GB/T 9704-2012 7.3.5.1 | 印章位置与效果需核对 | 印章用红色，不得出现空白印章；端正居中下压发文机关署名和成文日期，顶端上距正文（或附件说明）一行之内 |
| 版心 | GB/T 9704-2012 7.3.7 | 附件编排需核对 | 附件另面编排，在版记之前与正文一起装订；「附件」二字及顺序号用 3 号黑体顶格编排在版心左上角第一行，附件标题居中编排在第三行 |
| 版心 | GB/T 9704-2012 7.4.1 | 版记分隔线粗细需核对 | 分隔线与版心等宽，首条和末条用粗线（推荐 0.35mm），中间用细线（推荐 0.25mm） |
| 版心 | GB/T 9704-2012 7.4.2 | 抄送机关字体字号需核对 | 一般用 4 号仿宋体字 |
| 版心 | GB/T 9704-2012 7.4.3 | 印发机关和印发日期字体字号需核对 | 一般用 4 号仿宋体字 |
| 版心 | GB/T 9704-2012 7.5 | 页码编排需核对 | 4 号半角宋体阿拉伯数字，编排在版心下边缘之下，数字左右各放一条一字线，一字线上距版心下边缘 7mm；单页码居右空一字，双页码居左空一字 |
