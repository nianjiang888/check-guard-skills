# check-gov-doc-format 是什么

check-gov-doc-format 是公文印发前的「格式国标基线护栏」。依据 **GB/T 9704-2012《党政机关公文格式》**（国家质量监督检验检疫总局、国家标准化管理委员会 2012-06-29 发布，2012-07-01 实施，现行有效）与 **《党政机关公文处理工作条例》**（中办发〔2012〕14号，中共中央办公厅、国务院办公厅 2012-04-16 印发，2012-07-01 施行），在文件送印前把最容易出错也最容易被检查出来的格式硬伤扫一遍：发文字号用了中括号而不是六角括号、成文日期还在写汉字、层次序数把「1.」写成了「1、」、文种用了「申请」而不是「请示」、模板里还留着 2012 年就已删除的主题词。

公文「看起来没问题」往往只是没被认真核过。这些缺陷不影响文件内容，却会在收发文环节被打回重排——一份文件重排半小时，一天退三份就是半天。check-gov-doc-format 要做的，是把「印发前最后过一遍格式」变成可重跑、可量化、每条都能追到国标条款号的静态检查。

## 权威依据

| 依据 | 文号 / 标准号 | 效力 |
|---|---|---|
| 《党政机关公文格式》 | GB/T 9704-2012 | 2012-07-01 实施，现行有效，替代 GB/T 9704-1999 |
| 《党政机关公文处理工作条例》 | 中办发〔2012〕14号 | 2012-07-01 施行，规定 15 种法定文种与 18 个格式要素 |

规则库每条规则都带 `basis` 字段标注具体条款号（如「GB/T 9704-2012 7.3.5.4」），报告逐条显示，可直接拿去和办公室核。标准原文与条款对照见 `references/gb9704-methodology.md`。

## 能做什么

- **22 条自动判定规则**，覆盖版头、主体、版记、文种四层：
  - 版头：发文字号六角括号、年份全称、顺序号不编虚位不加「第」、上行文签发人
  - 主体：层次序数标点、成文日期阿拉伯数字与不编虚位、附件说明标点与全角冒号、附注格式、落款完整性
  - 版记：抄送末尾句号与全角冒号、印发机关和印发日期
  - 文种：15 种法定文种合法性、主题词残留、「会议纪要」冗余、「此页无正文」
- **23 项人工核对清单**：字体字号、页边距、版心尺寸、每面行数字数、印章位置、成文日期右空四字、页码编排等国标明确规定但纯文本无法自动判定的项，按文种与要素条件化输出，逐项给出标准值。
- 算「格式违规指数(0-100)」与「预计避免返工工时」，出可修正性报告。

## 边界（重要）

- **只读纯文本（.md/.txt）**。Word、WPS 需先转文本。**字体字号、页边距、印章位置这类排版层信息，纯文本里根本不存在**——本包不假装能查，而是把它们诚实列进「人工核对清单」并给出国标标准值，由人对照原件核。这是本包的设计原则：不把「需你确认」伪装成「已发现问题」。
- 规则覆盖通用格式，信函格式、命令（令）格式、纪要格式的特定要求（GB/T 9704-2012 第 10 章）以条件化清单形式给出，不做自动判定。
- 不涉及公文内容质量、政策合规性、文字校核——那是 check-spelling 和内容审核的事。
- 不修改文件、不拦截印发、不承诺 100% 准确。命中不等于必然被打回，未命中也不保证格式完美。

## 怎么用

```
python scripts/check.py scan <公文文件或目录> [报告输出路径]
python scripts/check.py rules                  列出全部规则（含条款号）
python scripts/check.py ledger <目录>           输出 JSON，供脚本消费
python scripts/check.py version
python scripts/smoke_test.py                    四档样例隔离实跑自检
```

报告分两节：第一节是自动检出的问题（带国标条款号），第二节是人工核对清单（带标准值）。末尾附机器可读的 `GOVDOC_RESULT {...}` 判定块。

退出码：0 干净，1 有命中，2 输入输出错误，3 命令写错。**本域不存在一票否决级项，故不设「极端」判定，退出码 4 不触发。**

## 免费版与付费版

免费版跑 8 条高频规则（发文字号、成文日期、层次序数、文种），付费版跑全量 22 条自动规则 + 23 项人工核对清单并附逐条整改建议。当前分发版本为免费版，frontmatter 中保留了 A2M 计费三件套的配置位置，改收费时启用即可。

## 与其他 check 成员的关系

- check-tender-rejection：校验「标书废标雷区」，面向投标场景。
- check-accessibility：校验「可访问性基线」。
- check-spelling：校验「文字与排版」是否干净，与本包互补——它管错别字，本管格式要素。
- check-links：校验「引用关系」是否断裂。
- check-docs：校验「文档与代码一致性」。
- check-gov-doc-format（本包）：校验「公文格式是否符合 GB/T 9704-2012」。

check-gov-doc-format 专注「党政机关公文格式国标合规」这一层。
