# 链接常见坑位（check-links 覆盖的清单）

| 坑位 | 典型表现 | 严重度 | 为何危险 |
|---|---|---|---|
| import 缺失 | 代码里 `import "./missing.py"` 但文件不在 | 极端 | 构建/运行直接失败，产物不可发布 |
| 相对文件缺失 | 文档 `![](./missing.png)`、配置 `include: x.yaml` 找不到 | 高 | 破图、断链、子文档打不开 |
| 链接语法非法 | URL 内含空格、`[站](www.x.com)` 缺协议头 | 高 | 解析器丢弃或错乱，点击无效 |
| 页内锚点失效 | `[章节](#nope)` 但文档没有对应标题 | 中 | 点击跳转无反应 |
| 占位域名 | 链接指向 `example.com` / `your-domain` / `localhost` | 中 | 发布后读者打不开，等于死链 |
| 空链接 | `[]()` 或 `href=""` | 中 | 点击无反应，体验残缺 |
| 路径逃逸根 | 引用 `../../etc/x` 逃出仓库根 | 中 | 既断裂也指向项目外，搬运即失效 |
| 目标首尾空白 | `]( ./x )` 或 `href=" x "` | 低 | 常被解析器忽略导致打不开 |
| 重复锚点 | 两个 `# 简介` 标题生成相同锚点 | 低 | 跳转必然指向第一个，歧义 |

## 误报控制

- 测试/示例专用文件（文件名含 test_/example/sample、内容含 fixture/测试专用示例 标记）跳过扫描。
- 抽取文件引用时，跳过明显的裸域名（`www.x.com`、`example.com`）与带 `://` 的外部 URL，避免把外链误判为本地文件缺失。
- 锚点匹配采用 GitHub 风格 slug（去标点、转小写、空格转连字符），与常见渲染器对齐。

## 不属于本包范围

- 实时 HTTP 探活（联网检查外链是否 200）—— 那是运行时监控的事，本包不联网。
- 链接内容的正确性（点开之后对不对）—— 静态文本检查看不到运行时。
- 安全层面的外泄通道检测 —— 那是 guard-network 的事。
