# 常见误报与边界（check-accessibility）

本文件列出发包前已知、且已做规避处理的几类边界，便于使用者理解「为什么有时没报、为什么有时报了但可关」。

1. img 缺 alt 的边界：只要 <img> 标签内无 alt= 即判定（高）。装饰性图片本应写 alt=""（空 alt 表示装饰），但引擎只判「有没有 alt 属性」，空 alt 不算缺失，不会误报。
2. 按钮无标签的边界：A11Y-BTN-NO-LABEL 用「<button> 内无文字且无 aria-label」判定。若按钮内有图标字体但无文字，仍会报——这是有意为之，建议补 aria-label。
3. html 缺 lang 的边界：仅对 .html/.htm 生效；组件文件（jsx/tsx）通常不写 <html> 故不触发该规则，避免误报。
4. 无 title 的边界：A11Y-NO-TITLE 用「有 <html> 却无 <title>」复合判定，仅对 .html/.htm 生效。
5. 标题层级跳跃的边界：同时解析 Markdown # 与 HTML <h1>-<h6>，按「相邻层级差 >1」判定，不读章节语义。
6. 已接入可访问性的边界：A11Y-CLEAN 仅做鼓励信号，不计入发现项、不提升判定等级；它存在的意义是「你已经做了该做的，给予正向标记」。
7. 测试 / 示例文件：文件名含 test_/example/sample，或内容带明确测试标记（fixture/测试专用示例）会被跳过。真实页面即使正文出现 example 等词也不跳过，宁可在示例上多扫，也不在真实页面上漏报。
8. 合规红线：本包所有源文件与压缩包均不含明文协议头、真实地址、绝对路径、BOM 与 CRLF，可安全上架分发。
